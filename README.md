🎮 Tic Tac Toe Game

📌 About the Project

Tic Tac Toe is a simple and interactive two-player game where players take turns marking X and O on a 3×3 grid.

The objective is to get three marks in a horizontal, vertical, or diagonal row to win the game.

✨ Features

- Two-player gameplay
- Interactive game board
- Player X and Player O turns
- Automatic winner detection
- Draw detection
- Restart / Reset game option
- Simple and user-friendly interface

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

🎯 How to Play

1. Open the game.
2. Player X starts the game.
3. Players take turns selecting empty boxes.
4. The first player to get three marks in a row wins.
5. If all boxes are filled without a winner, the game is a draw.
6. Click Reset to play again.

🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open "index.html" in your browser.
